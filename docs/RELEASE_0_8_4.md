# Hearth and Hunger 0.8.4 — An Ogre Feast

The loading-screen rotation includes an Ogre and Flint tracking through snow, the clan feasting with some dark Ogre humor, and a battle scene with an Ogre wielding a tree. All three use the in-game character sprites as design references. No wounded animals appear in the loading art.

Combat violence, blood and the existing bite and swallow finishers remain unchanged. The Ogre-only menu and three independent frontier saves remain available.
