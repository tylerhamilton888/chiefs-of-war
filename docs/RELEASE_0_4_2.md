Download **ChiefsOfWar-Windows-0.4.2.zip**, choose **Extract All**, then double-click **ChiefsOfWar.exe** in the extracted folder. Windows may hide the .exe extension and show it as **ChiefsOfWar**. No Godot installation, editor or source-project setup is needed.

This packaging update retains the combat and customization work from 0.4.1. There is one clearly named game executable at the top level, a short START HERE guide, optional practice under Extras, and technical files under Support. Existing campaign saves remain separate from the download.

The release is gated on archive integrity, Windows GUI executable identification, and native Windows headless startup tests for the normal game and optional practice, including a path containing spaces and launching from another working directory. Practice must leave a campaign sentinel unchanged. These automated startup checks are not a human graphics or gameplay acceptance test.
