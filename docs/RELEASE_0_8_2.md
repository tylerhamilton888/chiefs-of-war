# Hearth and Hunger 0.8.2 — The Ogre Hearth

The title screen now opens the Ogre experience: choose one of three independent Ogre frontier hearths or the separate Ogre story. Creating a character opens the Ogre creator. Your original frontier save is preserved as hearth one; new Ogres can begin in empty hearths.

Old Orc campaigns, models and saves remain preserved for future use, but their menu entries and the old Orc practice launcher are removed from the player-facing game and package.

New illustrated loading screens set the mood and offer useful tips when entering the frontier or Ogre story.

Sundered Frontier remains an early playtest, and the existing creator offers a name and four hair-and-beard color choices on the existing illustrated Ogre, rather than multiple independently drawn hairstyles.
