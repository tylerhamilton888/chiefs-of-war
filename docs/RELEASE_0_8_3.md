# Hearth and Hunger 0.8.3 — The Road and the Hearth

The wounded-boar loading artwork has been replaced with an Ogre and Flint tracking through snow. A new loading illustration shows the clan feasting together. These join the existing Ogre-versus-goblin battle scene in the loading-screen rotation, with practical gameplay tips.

Combat violence, blood and the existing bite and swallow finishers remain unchanged. The Ogre-only menu and three independent frontier saves remain available.
