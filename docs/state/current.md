# Current project

The Fire We Carry is the sole playable campaign. The title opens or resumes the existing chapter save. Seven connected regions, the original story outcomes, household work and wagon travel are present. The previous standalone Orc, camp and Frontier entry points have been retired. Some enemies, terrain, buildings and sound effects originated in the Orc prototype and still serve the Ogre campaign.

The baseline is feature/hearth-and-hunger at 945a3d8, which has the same game source as v0.8.10. The old modes and their saves can be used together at that tag. The current game never reads or converts those saves. Retained Frontier actors and equipment data are source material for future combat work and are excluded from player exports.

Godot 4.4.1 validation passed for title start/continue, damaged-save handling, retired-save isolation, loading, chapter progression (94 checks), chapter quality (17), scale (13), navigation (161) and rendered dialogue/layout (100). The exported game data was launched in Godot on Linux. The release-tool suite passed 18 tests.
