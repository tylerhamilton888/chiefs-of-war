# Changelog

## 0.1.0 — 2026-10-29

- Established separate private Chiefs of War project and Godot architecture.
- Added four-direction illustrated character candidate and heavy iron outfit comparison.
- Replaced the initial painted environment with independent persistent props and editable terrain.
- Added damage, timber spawning/collection, modular wall/roof state, and derived collision.
- Added deterministic fire simulation, contained hearth safety, explicit ignition, extinguishing/wet protection, firebreaks, warned test disaster and recovery save.
- Added world inspection tools, save/load, Windows export preset, provenance, architecture notes and 35-check Godot test suite.

Not accepted as final art or finished gameplay. The generated axe-action sheet was rejected for inconsistent facing and clipping and is not used in-game.

## 0.2.0 — The First Hearth — 2026-10-29

- Returned to 2D after the rejected 3D experiment. Added reference-led inked/painted building, prop, portrait, leather and iron character candidates.
- Added timed directional strikes, range/facing gates, enemy telegraphs, armor mitigation, dodge cooldown/invulnerability and recovery at camp.
- Added actual woodcutting, tree fall feedback, collectible timber, ore gathering, three-stage storehouse construction, palisade placement and iron forging.
- Added enterable hall/forge/storehouse, portrait conversations, rest/rations, timber storage and autonomous worker gathering/depositing.
- Added optional five-step journal, campaign persistence, safe fire drill and checkpoint restore, free dousing and earth firebreaks.
- Added original synthesized impact sounds and actual-engine visual capture/integration tests.
